03

AI-COLLABORATIVE DELIVERY

AI 不是技能清單，
是我的工作方法。

01 / DEFINE

定義問題

先釐清限制、相容邊界與可驗收的結果。

02 / DIRECT

引導實作

把工作切成小範圍，提供脈絡並限制 AI 可以改動的部分。

03 / REVIEW

審查產出

逐段閱讀 diff、追查假設，修正看似合理但不符合系統的答案。

04 / VERIFY

完成驗收

用測試、實機流程與既有行為比對，確認交付真的成立。

責任怎麼分

我負責

  • 架構取捨
  • Code review
  • 測試與驗收

AI 協助

  • 探索方案
  • 產生初稿
  • 重複性修改
  • 補測試與文件

最後責任仍然在我：程式能不能合併、行為對不對、風險能不能接受。
