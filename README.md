# Jack Sun 履歷網站

以 Git 與既有履歷證據整理的繁體中文個人履歷網站。內容以 2021/12/21 起的沃草工作成果為主，並收錄過往經歷、Windows／WSL AI 系統與 Mac 工程工具。

## 技術範圍

- **前端**：Vue 2／3、Nuxt 2／3、React、Next.js、JavaScript、TypeScript、Pinia、Redux、HTML、CSS、SCSS、Tailwind CSS、styled-components、RWD
- **後端與 API**：Node.js、Express、Python、.NET 8、REST API、GraphQL、Prisma、MariaDB／MySQL、Firebase／Firestore、JWT、OAuth、MCP
- **測試與品質**：Vitest、Jest、Mocha、Playwright、Vue Test Utils、Supertest、Firestore Emulator、E2E、相容性驗證
- **雲端與交付**：Docker、Google Cloud Run、Cloud Build、GitHub Actions、Secret Manager、PM2、Systemd、Windows／WSL
- **AI 與系統整合**：Gemini Live API、llama.cpp、Ollama、ComfyUI、本機模型部署、Computer Vision／OCR、Win32／WASAPI、AI guardrails 與評估校準
- **裝置與自動化**：Swift、ScreenCaptureKit、AppKit、ADB、Android test provider、GraphHopper、OpenStreetMap、tmux

## 網站實作

本站使用 Semantic HTML、CSS Grid、CSS custom properties、OKLCH colors 與 Vanilla JavaScript，無框架、無 build step、無 runtime dependency。
